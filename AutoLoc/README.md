# AutoLoc - Plateforme de gestion de location de véhicules multi-agences

## Objectifs du projet
AutoLoc est une application Spring Boot permettant de gérer la location de véhicules pour plusieurs agences.

## Acteurs identifiés
- **Client** : Peut consulter les véhicules et effectuer des réservations.
- **Agent d'agence** : Gère les locations et retours de véhicules au quotidien.
- **Responsable d'agence** : Supervise l'activité de son agence et gère les véhicules.
- **Administrateur** : Gère l'ensemble du système, les utilisateurs et les agences.
